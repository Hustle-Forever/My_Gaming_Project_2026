Trust

Built paranoid on purpose

▸ Closed whitelist

The AI is forced into a single function whose action enum is the six actions + none. Output is re-validated server-side before anything queues. Unknown action at the bridge? Logged, skipped, acked.

▸ Keys stay sealed

Customer AI keys are AES-256-GCM encrypted at rest, decrypted only inside the one function that calls the model, never sent to a browser, never logged.

▸ Pay-gate everywhere

One boolean — active — gates both the command path and the bridge poll with a 402. Inactive account, dead pipe. Stripe plugs into the same switch later.

▸ Outward-only bridge

The FiveM resource polls out over HTTPS with a rotatable per-tenant token. Customers never open a port, never touch a firewall. Firestore denies all client access — the API is the only door.
